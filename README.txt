Aroma Cafe Website

Files:
- index.html: Home page
- about.html: About Us page
- menu.html: Menu page (includes a drinks-and-prices table)
- contact.html: Contact form page
- style.css: Shared styling for all pages
- script.js: Client-side validation for the contact form
- images/: Images used by the website

How to run:
1. Extract the ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser (double-click it from File Explorer).
4. Use the navigation menu to move between pages.

Note:
The contact form demonstrates front-end validation only. It does not send messages to an email inbox or server.
